# Idea Board

A self-contained, single-file drawing app. No installation, server, external libraries, or tldraw license required.

## Run

Download `index.html` using GitHub's **Download raw file** button, then double-click it to open in Edge or Chrome. All code, styles, and icons are included. It works without internet.

For web hosting, upload `index.html` to any static web host. Adding the file to this repository does not by itself enable GitHub Pages.

## Features

Pen, object eraser, rectangles, ellipses, arrows, text, notes, images, move/resize, colors, undo/redo, zoom, light/dark canvas, and up to 20 named pages. Use the half-circle button next to Export PNG to change the background.

## Your drawings

Each browser profile has its own local board. Drawings are not uploaded to GitHub or the hosting server. Browser storage for local HTML files varies: use **Save file** for reliable backups and **Open file** to restore all pages and embedded images. Export PNG saves the current page as an image.

Use separate browser profiles or devices for different users, and one editing tab at a time. Clearing browser data or moving to another browser/address may make local drawings unavailable. Export a backup before moving. Older tldraw-format boards are not compatible.

This is a basic personal whiteboard, without live collaboration, accounts, or cloud backup.
