# Release history

## v2.2 — Visio Export Preview (2026-10-02)

- Added offline .vsdx export for the current page or all pages.
- Added native shapes, text, embedded pictures, page names, annotations and connector attachment records.
- Added explicit conversion warnings and export error reporting.
- Retained the v2.1 drawing and editing tools.
- Native Microsoft Visio interoperability remains unverified; export is labelled Preview.

## v2.1

- Optional obstacle-aware connector routing.
- Broader keyboard navigation and accessibility support.

Earlier releases added search/outline, PDF export, structured annotations and bounded undo history.
